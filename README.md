# PharmaPulse: HCP Engagement & Pharma Sales Intelligence Platform

PharmaPulse is an end-to-end healthcare analytics and data engineering project focused on HCP engagement, pharma sales performance, territory analysis, campaign effectiveness, and next-best-action recommendations.

## Project Objective

The goal of this project is to simulate how a pharma commercial analytics team can use data to improve HCP engagement, medical representative performance, territory planning, and sales decision-making.

## Business Questions

- Which HCPs generate the highest revenue?
- Which territories are underperforming?
- Which medical representatives are meeting their targets?
- Which product categories are driving growth?
- Which campaigns are creating strong HCP engagement?
- Which HCPs may become disengaged?
- Which HCP should each rep prioritize next?
